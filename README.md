# Declarative GCP Platform Factory & Governance GitOps

An automated, self-service **Internal Developer Platform (IDP) as Code** for Google Cloud.

This platform automates enterprise cloud provisioning for multi-tenant data and engineering squads using **Declarative Project Definitions**, **Keyless GitOps (Workload Identity Federation)**, **Private Service Connect (PSC)**, and **Continuous IAM Security Auditing via BigQuery**.
